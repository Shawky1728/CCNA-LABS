# CCNA Labs

A collection of Cisco Packet Tracer practice labs covering core networking concepts and protocols required for the Cisco Certified Network Associate (CCNA) certification.

## Topics Covered

- **Basic**: Initial device setup, basic router and switch configurations, and host addressing.
- **VLAN**: Virtual LAN configuration, trunking (802.1Q), and inter-VLAN routing (Router-on-a-Stick / Layer 3 switching).
- **EtherChannel**: Link aggregation using PAgP and LACP protocols.
- **STP**: Spanning Tree Protocol, PVST+, and Rapid PVST+ configuration.
- **Routing**: Static routing, default routing, and dynamic routing protocols (such as OSPF).
- **IPv6**: IPv6 addressing, static routing, and dual-stack implementation.
- **ACL**: Standard and Extended Access Control Lists for network traffic filtering.
- **NAT**: Static NAT, Dynamic NAT, and Port Address Translation (PAT).
- **Redundancy Protocols**: First Hop Redundancy Protocols (FHRP) including HSRP.
- **Port Security**: Switchport security, MAC address limiting, and violation actions.
- **DHCP Spoofing**: DHCP Snooping configuration and switch security.
- **Securing Router**: Management plane hardening, password protection, and SSH/Telnet security.
- **CDP and LLDP**: Cisco Discovery Protocol and Link Layer Discovery Protocol configuration.
- **NTP**: Network Time Protocol synchronization.
- **WLAN**: Wireless LAN fundamentals and WLC/AP setup.
- **Backup**: Managing Cisco IOS configurations and image backups.

## Requirements

- Cisco Packet Tracer (recommended version 8.0 or later)

## How to Use

1. Clone or download this repository:
   ```bash
   git clone https://github.com/Shawky1728/CCNA-LABS.git
   ```
2. Navigate to any lab directory.
3. Open the `.pkt` file in Cisco Packet Tracer.
4. Review the topology, verify configurations, and practice commands using the CLI.
